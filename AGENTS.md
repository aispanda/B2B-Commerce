# Lean website maintenance

- Read `Data Model/README.md` for context, sources, preview and deployment steps.
- Preserve existing documents and pages; do not reorganize or rewrite them unnecessarily.
- Prefer self-contained zero-build HTML/CDN pages and the minimum possible files.
- Do not add unsolicited boilerplate, dashboards, frameworks or dependencies.
- Keep each page's editable source and brief maintenance notes with it, usable by any agent.
- Retain direct GitHub Pages deployment from `main` / root and the root `.nojekyll`.
- Follow the page folder's AGENTS.md and preserve its accepted behavior and source authority.
- Use local backups before edits and Git commits for shared history; do not publish backups or secrets.
- Verify the changed page and return its shareable GitHub Pages URL after deployment.
