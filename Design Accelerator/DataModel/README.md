# Data model reference

The existing interactive object guide is maintained at [DataModel](../../DataModel/) and published at [Commerce object guide](https://aispanda.github.io/B2B-Commerce/DataModel/). This folder provides its place in the accelerator without copying its project-specific org snapshot into the customer-neutral requirements library.

The guide includes detailed journey views, object definitions and relationship diagrams. Its source workbook, examples, observed metadata and custom objects reflect one reviewed environment. Treat them as discovery leads; verify applicability and current Salesforce documentation for each target project. Follow the [guide's maintenance instructions](../../DataModel/README.md) when updating its source.
