# Commerce Design Accelerator

Reusable design references for medical-device and supply commerce projects.

- [Requirements](Requirements/) — customer-neutral personas, journeys, needs, goals, pain points, jobs, candidate requirements and a source-linked Salesforce capability map.
- [Data model](DataModel/) — entry point to the existing interactive object guide and its original source files. The guide is a project-specific snapshot, not a universal schema.

Start with the [requirements guidance](Requirements/README.md). Confirm policies, licensing, permissions, configuration and current documentation for each project. Do not place customer data, credentials or org-specific evidence in the reusable requirements folder.
